相対ローテーション・グラフ（RRG）：プロのローテーション地図

ユリウス・デ・ケンペナーが考案した相対ローテーション・グラフ（RRG）は、どの資産やセクターが基準指数に対して強くなっているか弱くなっているか、そしてどのくらいの速さかを視覚的に見る方法です。各資産を別々に見るのではなく、すべてを4象限の平面に置き、誰が先行し誰が遅れているかを一目で把握します。機関投資家のツール（StockCharts、ブルームバーグ）で、個人はほとんど使いません。

学べること

何か

RRGは各資産を、4象限に分けた平面上の点として描きます。常に指数（例：S&P500）に対して測ります。絶対的に上がっているかではなく、市場より良いか悪いか、そしてその優位が加速しているか薄れているかを示します。多くの資産を一度に比較し、どこに焦点を当てるかを決めるためのものです。

二つの軸

横軸はRS-Ratio：指数に対する相対的な強さ（右＝市場より強い、左＝弱い）。縦軸はRS-Momentum：その強さの「速さ」（上＝優位が加速、下＝薄れる）。中心は基準指数（値100）。中心にいることは、市場と同じ動きをしていることです。

4つの象限

右上、リーディング（強く加速中）：今の勝者。右下、ウィークニング（強いが勢いを失いつつある）。左下、ラギング（弱く下落中）：敗者。左上、インプルービング（まだ弱いが勢いを取り戻しつつある）：次のリーダー候補。各象限の色が、その健康状態を一目で要約します。

ローテーション（時計回り）

RRGの強力な点は、資産が象限の間を「時計回り」に回りやすいことです：インプルービング → リーディング → ウィークニング → ラギング → そしてインプルービングへ戻る。この循環が先読みを助けます。「インプルービング」に入るセクターはリーダーの局面を始めているかもしれず、「リーディング」から「ウィークニング」へ抜けるものは優位を使い果たしつつあるかもしれません。

テール（軌跡）

各点は「テール（尾）」を引きます。直近数週間の軌跡で、どこから来てどこへ向かうかを示します。長く方向が明確なテールは強く安定したローテーションを、短く絡んだテールは迷いを示します。テールは静止した写真を、ローテーションの傾向を映す動画に変えます。

使い方

古典的な用途はセクターローテーションです。リーディングまたはインプルービング象限のセクターでポートフォリオを固め、ラギング象限のものは避ける（または減らす）。株式、国、資産クラスを同じ指数に対して比較するのにも使えます。常に慎重に選んだベンチマークと、ノイズを濾すために週足で使います。

限界（正直に）

RRGは「相対的」な強さを測り、絶対ではありません。市場全体が下げれば、リーディング象限にある資産も価格は下がり得ます——下げ幅が小さいだけです。それ単体では入場シグナルではありません。どこを見るかを示すもので、いつ入るかではありません。それには自分の分析とリスク管理が要ります。そして平均に基づくもの同様、一歩遅れます。

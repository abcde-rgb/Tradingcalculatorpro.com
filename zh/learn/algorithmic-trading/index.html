你将学到

是什么(系统化 vs 主观)

算法是一套精确到计算机无需人为判断即可执行的入场、出场和仓位规则。系统化交易 = 规则决定;主观交易 = 你决定。真正的优势不是速度,而是把恐惧和贪婪从执行中剔除。

回测

在冒真钱风险前,用历史数据测试策略。必不可少,但也危险:很容易『曲线拟合』(过拟合)到回测光鲜,实盘却失败。黄金法则:保留算法从未见过的样本外数据并在那里验证。完美的回测通常是危险信号,而非成功。

执行、API 与延迟

机器人通过 API 连接券商,自动读取价格并发送订单。对散户,毫秒很少重要;专业高频交易确实为主机托管(服务器紧邻交易所)付费。真正影响你的是:若不建模,滑点和手续费会把盈利的回测变成亏损的系统。

陷阱:过拟合与偏差

系统的沉默杀手:对过去数据过拟合;幸存者偏差(只用仍然存在的股票测试);前视偏差(使用当时不可能拥有的数据);以及忽略真实成本。每一个都让回测说谎。你调的参数越多,越可能记住噪声而非学到信号。

自动化风险

有缺陷的算法能在几分钟内清空账户:一个 bug、损坏的数据或超出预期范围的市场,机器人就会全速重复错误。不可妥协:『急停开关』、写死的每日亏损上限、警报和人工监督。绝不要让实盘系统无人看管地运行。

深入理解移动平均线：SMA、EMA 与交叉

移动平均线是技术分析中使用最多的指标：它平滑价格噪声，让你一眼看出趋势的方向。这里讲清楚它们到底是什么、该用什么周期、交叉策略（包括黄金交叉和死亡交叉），以及如何把它们当作动态支撑和阻力来用。记住：它们是滞后指标——确认趋势，而不是预测趋势。

SMA 与 EMA：该用哪个

移动平均线是最近 N 根K线的平均价格，每根K线都会重新计算。SMA（简单）对所有数据一视同仁；EMA（指数）给近期数据更高权重，所以反应更快，但假信号也更多。没有哪个"更好"：SMA 更平滑、对判断大趋势更可靠；EMA 更快，适合短线。两者都是滞后指标：它们在价格已经转向之后才动。

该选什么周期

周期（N）决定均线的性格。短（5-20）：动能与即时的支撑/阻力。中（20-100）：修正与回撤的目标位。长（100、150、200）：大趋势——200 周期是机构级参考。有人用斐波那契周期（89、144、233）。经验法则：N 越大越平滑越慢；N 越小越快越吵。让 N 匹配你的时间框架。

策略一：价格与均线交叉

最简单的一种。买入信号：价格自下而上穿过均线并站稳其上（上升趋势）；卖出信号：自上而下穿过并跌破（下降趋势）。在有方向的行情里好用，在震荡里失灵（来回打脸）。把它当作方向过滤器，而不是唯一的扳机。

策略二：双均线交叉

不看价格，而是看一条快线和一条慢线的交叉（比如 30 和 100）。快线上穿慢线买入；下穿卖出。它比价格交叉过滤更多噪声，但代价是更滞后：入场更晚。这是趋势跟随的经典做法。

策略三：带过滤的三均线交叉

再加一条慢均线（比如 200）当趋势过滤器。只有当两条更快的均线都在过滤线之上才买；都在其下才卖。它只顺着大趋势方向交易，从而减少假信号，用频率换质量。交易更少，但更干净。

黄金交叉与死亡交叉

最有名的两个交叉，发生在 50 与 200 周期均线之间。黄金交叉：50 向上穿过 200 → 长期看涨信号。死亡交叉：50 向下穿过 200 → 看跌信号。它们慢、来得晚（转向早已开始），但追随的交易者和媒体太多，以至于自身变得重要。当作背景比当作精确扳机更好。

均线作为支撑/阻力

价格往往把长周期均线当作决策区来尊重。如果在均线上强力反弹，多半趋势延续；如果清晰跌破，多半反转；如果触碰后犹豫，则两个方向都可能突破。有汇合时价值更高：当均线与一条水平位、一个斐波那契或一个整数位重合时，这个区域的分量就大得多。

指标家族

均线属于趋势类指标（滞后）：在有方向的行情里出彩，在震荡里失灵。最好把它和其他家族搭配：振荡类（RSI、随机指标、CCI）能预判转向，却在趋势里失灵；波动类（布林带，本质是均线±标准差）；趋势强度类（ADX）；以及成交量。关键不是堆指标，而是搭配彼此互补的家族。

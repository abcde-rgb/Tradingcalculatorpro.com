GDP增长

GDP 衡量一个国家一个季度内产出的全部:它是经济的温度计。若增长超预期,货币往往走强(经济强劲→可能加息);若不及预期则走弱。真正推动市场的不是数字本身,而是相对预期的意外。

CPI通胀

CPI 衡量通胀:消费者价格上涨了多少。它是最能撼动市场的数据之一,因为央行会通过加息来抑制高通胀。CPI 高于预期→更高利率→货币走强但股市紧张。要盯'核心'读数(剔除能源和食品)。

利率

央行设定的利率是资金的价格,也是货币的头号驱动因素。更高的利率吸引外资、令货币走强,但会给经济降温,通常压制股市。重要的不只是决议本身,还有对未来数月的'措辞'(鹰派/鸽派)。

NFP

非农就业(NFP)是美国每月第一个周五公布的就业报告:全球最受关注的宏观数据。它会在第一分钟内让美元、黄金和指数出现巨大波动峰值。新手守则:公布前不要持仓;点差会瞬间放大,价格会跳动。

失业率

失业率衡量正在找工作却没有工作的人所占的百分比。失业越低=经济越强=对利率和货币的上行压力。要与非农和薪资一起看:'过热'的就业市场会引发通胀担忧。和所有宏观数据一样,推动价格的是与预期的偏差。

使用方法

经济日历列出将公布哪些数据、几点公布、预期影响多大。用法要反过来:不是去'猜'反应,而是知道什么时候别交易。每天早上看看当天的高影响事件,在'红色'数据公布前的几分钟内避免开仓。

影响程度

事件按影响标注:红色(高:利率、CPI、非农)、橙色(中)、黄色(低)。红色事件可能在几秒内让市场波动数百点,伴随极宽点差和滑点。对新手来说,明智之举是等数据出完、交易随后的反应,而不是去赌那个数字。

市盈率

市盈率(价格/盈利)告诉你为这只股票支付了多少年的当期盈利。市盈率 15 算'正常';40 以上意味着市场预期高增长(贵且一旦不及预期就脆弱);极低可能是便宜货……也可能是陷入困境的公司。只有与同行业及公司自身历史比较才有意义。

每股收益

每股收益(EPS)是公司利润除以股数:每股赚多少。这是股市每季度最看重的数字;若超预期,股价通常上涨。关键在于趋势(是否逐年增长?)以及相对分析师预期的意外。

营收增长

营收增长衡量销售额同比增加了多少。它是企业真正在扩张的最干净信号,尤其对尚未盈利的年轻公司而言。销售加速=动能;销售停滞=警讯,即便靠削减成本让利润暂时撑住。

股息

股息是公司以现金分配给股东的那部分利润,通常每季度一次。'股息率'(股息/股价)告诉你每年能领多少。对长期投资、靠分红生活很有吸引力,但要当心:异常高的股息率有时掩盖着一家在衰退的公司。

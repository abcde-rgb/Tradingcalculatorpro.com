相对轮动图（RRG）：专业人士的轮动地图

由 Julius de Kempenaer 创建的相对轮动图（RRG），是一种直观地看出哪些资产或板块相对于一个基准指数在增强或减弱、以及速度如何的方式。你不必逐个看每个资产，而是把它们全部放在一个四象限平面上，一眼就能看出谁领先、谁落后。这是一个机构工具（StockCharts、彭博），散户几乎不用。

你将学到

它是什么

RRG 把每个资产画成四象限平面上的一个点，始终是相对于一个指数（如标普500）来衡量的。它不告诉你某物在绝对意义上是否上涨，而是它比市场做得更好还是更差，以及这种优势在加速还是消退。它用来一次比较很多资产，并决定该把注意力放在哪。

两个坐标轴

横轴是 RS-Ratio：相对指数的强弱（右边=比市场强，左边=更弱）。纵轴是 RS-Momentum：这种强弱的“速度”（上=优势在加速，下=在消退）。中心是基准指数（数值 100）：位于中心就是表现得跟市场一样。

四个象限

右上，领先（强且加速）：当下的赢家。右下，走弱（强但失去动能）。左下，落后（弱且下滑）：输家。左上，改善（仍弱但重拾动能）：可能的下一批领先者。每个象限的颜色一眼概括它的健康状况。

轮动（顺时针）

RRG 的厉害之处在于资产往往在象限之间按“顺时针”轮动：改善 → 领先 → 走弱 → 落后 → 再回到改善。这个循环帮你预判：一个进入“改善”的板块可能正开始一段领先行情；一个从“领先”走向“走弱”的，也许正在耗尽它的优势。

尾巴（轨迹）

每个点都拖着一条“尾巴”：最近几周的轨迹，显示它从哪来、往哪去。一条长而方向清晰的尾巴意味着强而稳定的轮动；短而缠绕的尾巴则是犹豫。尾巴把一张静止的照片变成一部轮动趋势的电影。

如何使用

经典用法是板块轮动：把仓位配置在“领先”或“改善”象限的板块，回避（或减配）“落后”象限的。它也可以拿股票、国家或资产类别去和同一个指数比较。始终配合精心挑选的基准，并在周线级别过滤噪声。

局限（诚实）

RRG 衡量的是“相对”强弱，不是绝对：一个资产可以处在“领先”象限，若整个市场下跌，它照样价格下跌——只是跌得少些。它本身不是入场信号：它告诉你该看哪里，而不是何时进场；那需要你自己的分析和风险管理。而且，和一切基于均线的东西一样，它慢半拍。

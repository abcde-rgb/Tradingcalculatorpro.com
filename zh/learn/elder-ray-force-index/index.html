埃尔德系统：三重滤网、Elder-Ray 与 Force Index

亚历山大·埃尔德（Alexander Elder）是转行做交易的精神科医生，也是《以交易为生》的作者。他围绕三大支柱——心智、方法、资金（心理、系统与管理）——以及若干自创、如今少用的工具，建立了一套完整的方法。这里介绍主要的几样：三重滤网、Elder-Ray、Force Index 和 Impulse System，以及它们真正的价值与局限。

三个 M：心智、方法、资金

对埃尔德来说，赢利取决于同等重要的三条腿：心智（心理与纪律，以免自我破坏）、方法（一个有优势、规则清晰的系统）和资金（风险与仓位管理）。他的核心信息是：技术系统只是三者之一，多数人输在另外两个上。他的指标服务于“方法”，但没有另外两个 M 就不够。

三重滤网

这是他最有影响力的想法：在三个时间周期上分析，以免逆流交易。第一屏：在“高”周期（如周线）用均线或 MACD 定出主趋势。第二屏：在中间周期（日线）用振荡指标等待一个逆主趋势的回调。第三屏：在低周期，当回调衰竭时，顺着更大的趋势进场。趋势在上，择时在下。

Elder-Ray（多头/空头力量）

Elder-Ray 通过把每根 K 线的极值与一条指数均线比较，来衡量买卖双方的力量。多头力量（Bull Power）是最高价减去 EMA（多头在“共识”之上推了多少）；空头力量（Bear Power）是最低价减去 EMA（空头把它压了多深）。这两股力量与价格之间的背离，会提示可能的衰竭。它是市场脉搏的简易 X 光。

Force Index（力度指数）

Force Index 把定义一段走势的三件事合成一个数字：方向（涨或跌）、幅度（多少）和成交量（力度多大）。它以价格变动乘以成交量来计算，通常用均线平滑。Force Index 的尖峰与背离，有助于把真突破（有量）与假突破（无量）区分开。

Impulse System（脉冲系统）

Impulse 同时依据两个条件给每根 K 线上色：一条 EMA（趋势）和 MACD 柱状图（动量）。绿色：两者都升 → 允许买（禁止做空）。红色：两者都降 → 允许卖。蓝色：不一致 → 没有明确许可。它不是入场信号，而是一套“审查”系统：它告诉你不“可以”做什么，只让你顺着惯性交易。

局限（诚实）

埃尔德系统经典、稳健且很有教学价值，但它出自 90 年代，其指标并无魔法优势：和许多指标一样，都是均线与动量的组合，且有滞后。它真正的价值不在 Force Index 或 Elder-Ray，而在于思维框架（三个 M）以及顺着更高周期交易的纪律。把它当作一套完整的管理方法，而不是万无一失的指标。

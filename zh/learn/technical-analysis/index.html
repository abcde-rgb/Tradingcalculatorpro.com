线性（算术）刻度——「自动」的那种

每一格纵向刻度代表相同的美元数。$10 的波动占据相同高度，无论价格在 $20 还是 $500。几乎所有平台的默认设置。 用数字看问题：从 $10 到 $20 是 +100%（本金翻倍）；从 $100 到 $110 只是 +10%。在线性刻度上这两段都是 $10 → 占据完全相同的高度，尽管其中一段对你钱包的意义大十倍。只要价格区间一大，就会扭曲你对风险的感知。

对数（半对数）刻度——专业人士用的

每一格纵向刻度代表相同的百分比，而非相同美元。+50% 在任何价位都占据相同高度。 用数字看：从 $10 到 $20（+100%）与从 $100 到 $200（+100%）或从 $1,000 到 $2,000（+100%）占据相同高度。图表反映真正重要的——百分比回报，而非绝对数值。所以对于翻了很多倍的资产（比特币从 $100 到 $60,000、英伟达……），这是看清全貌的唯一方式：线性刻度上早年是贴着底部的一条平线；对数刻度上你能清楚看到每一个周期。

何时用哪一种

实用规则： • 对数 → 长周期图（周线/月线）、加密货币、涨幅巨大的股票，以及价格在屏幕上走过超过约 30-40% 时。这是中长线严肃分析的默认选择。 • 线性 → 日内和小区间，价格几乎不怎么按 % 波动，两种刻度看起来几乎一样。例：EUR/USD 从 1.0800 到 1.1000 约 1.9% → 对数或线性没差别。 注意：平台上的「自动」不是第三种刻度；它只是自动适配缩放。刻度仍是你所选的线性或对数。

为什么它会改变你的分析（最关键）

几乎没人讲的关键：趋势线、通道、形态和斐波那契在对数和线性上画出来是不同的。一条在线性上撑住的趋势线，在对数上可能已经跌破——反之亦然——在同一张图上给你相反的信号。 用数字看：一条连接 $100 → $200 → $400 的上升趋势。在对数上每一段都是 +100%，所以三点连成一条完美的直线，趋势线可靠。在线性上同样的上涨是一条加速上翘的曲线；你画一条直线，它会偏离价格，给出假突破。所以专业人士会选定一种刻度（长线几乎总是对数），固定住并保持一致：分析中途换刻度，就是在骗自己。

支撑位

价格下方买盘往往能止住下跌的区域。价格在此反弹的次数越多越可靠——把它画成一条区带,而不是精确的一条线。不要仅仅'因为有支撑'就买入:等待确认(拒绝K线或成交量放大)。若被明确跌破,该支撑就变成阻力。

阻力位

价格上方卖压往往能压住上涨的区域:很多人获利了结的'天花板'。操作方法与支撑相同但方向相反(寻找拒绝信号来卖出或锁定利润)。若价格带量强势突破,该阻力通常会转为支撑。

支撑/阻力区域

实际上价格并不会在某个精确数字上反转,而是在一个区域内。把支撑/阻力画成区带(如 99.5–100.2)而不是一条线,能避免一次插针或影线过早把你扫出局,也更符合真实市场的运行方式。

突破

价格穿越支撑或阻力的时刻。放量突破通常是真实的,会开启新一段行情;缩量突破往往是陷阱(假突破),会重新回到区间内。新手技巧:等K线收盘站稳在该水平之外,而不是刚一触碰就进场。

上升趋势

价格形成一浪高于一浪的高点和低点:每次回调的低点都高于上一次。这是最容易赚钱的环境——在回调中买入。只要最近的关键低点没被跌破,上升趋势就依然有效('趋势是你的朋友')。

下降趋势

价格形成一浪低于一浪的高点和低点:每次反弹都止步于上一次之下。这里自然的做法是在反弹中卖出或做空,而不是'抄底'。过早去接底部,是最容易让账户爆仓的错误之一。

横盘

价格在支撑与阻力之间横向震荡,没有明确方向。策略:在底部附近买、在顶部附近卖,或者空仓等待突破。市场有 60-70% 的时间处于震荡区间,所以懂得在这里'不交易'本身也是一种能力。

趋势结构

结构是趋势的'脊梁':高点和低点依次抬高(上升)或依次降低(下降)。当这一序列被打破——比如上升趋势中价格创出更低的低点——就是趋势可能反转的第一个信号(性质转变)。

SMA

简单移动平均线:最近 N 个周期收盘价的平均(如 50 或 200)。它平滑噪音并显示方向:价格在其上方 = 偏多。50 与 200 最受关注,二者的交叉(金叉/死叉)有半个市场在盯。反应偏慢,但可靠。

EMA

指数移动平均线:与 SMA 类似,但给近期价格更高权重,因此转向更快、更贴合价格。常用:9、20、50。更适合快速交易;代价是比 SMA 有更多假信号。很多人用 EMA 择时进场,用 200 SMA 把握大局。

RSI

相对强弱指数(0-100):衡量价格是否涨得或跌得太快。>70 = 超买,<30 = 超卖。但在强趋势中它可能长期'超买'——不要仅凭它逆势操作。它最强的信号是背离(价格创新高而 RSI 没有)。

MACD

通过比较两条均线(12 和 26)与一条信号线来衡量动能。MACD 线上穿信号线 = 多头动能;下穿 = 空头。柱状图显示动能在加速还是衰竭。适合确认趋势,在震荡市中不可靠。

布林带

布林带:一条 20 周期均线加上下 ±2 个标准差的两条带。约 90% 的价格都在带内,所以单纯触碰带并不是反转信号。它最强的用途是波动率:当带收窄(挤压)时,往往随后会有一波大行情。

斐波那契

斐波那契回撤:一段行情之后,价格常回撤到 38.2%、50% 或 61.8% 再继续。从这段行情的起点画到终点,用来寻找顺势的进场区。61.8% 最受关注;跌破它,行情就失去了力度。

概念

同时在多个时间周期上分析同一品种。大周期(日线/4 小时)决定方向,小周期(15 分/5 分)精修进场。它能避免新手的经典错误:在 5 分钟图上买入,而此时日线正在下跌。

自上而下方法

自上而下的方法:先看大周期决定方向偏好(偏多还是偏空?),再下到中周期定位区域,最后到小周期找进场触发。始终顺着大周期方向交易,能显著提高胜率。

Smart Money / ICT

“聪明钱”方法（由ICT推广）试图追踪机构的足迹：他们在哪里建仓、如何猎取散户流动性，以及价格会回到何处。它属于主观判断——把它作为共振条件，而不是万能系统。

你将学到

市场结构（BOS / CHoCH）

高点与低点的序列。'结构突破'（BOS）确认趋势延续；'性质转变'（CHoCH）预警可能反转。它是其他一切的基础。

订单块（Order Block）

在强劲冲动性走势前的最后一根反向K线。被解读为机构下单的足迹；价格常在继续前回到该区域。

公允价值缺口（FVG / 失衡）

由三根K线形成的缺口，价格移动过快留下未成交的失衡。市场往往会回来'填补'该区域后再继续。

流动性（买方 / 卖方）

在高点上方（买方）和低点下方（卖方）堆积的止损簇。这是大玩家执行大仓位所需对手方的地方。

流动性猎取（猎止损）

短暂突破高点或低点以'扫掉'那些止损、随后急速反转的插针。经典陷阱：在真正的行情前猎杀散户。

溢价 / 折价（OTE）

把区间对半分：在'折价'（50%以下）买入，在'溢价'（50%以上）卖出。最佳入场区（OTE）通常在斐波那契61.8-79%回撤处。

缓解（Mitigation）

当价格回到订单块以'缓解'未成交的订单，然后继续趋势。这是该方法首选的入场：等待回到该区域，而非追涨杀跌。

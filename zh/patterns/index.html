图表形态

42 个形态

  • 头肩顶 — 上升趋势后形成的看跌反转形态。由三个峰组成：中间的（头部）高于两侧的（肩部）。
  • 头肩底 — 下降趋势后形成的看涨反转形态。由三个谷组成：中间的（头部）低于两侧的（肩部）。
  • 双顶 — 由两个连续的高点在同一水平形成的看跌反转形态，随后向下突破。
  • 双底 — 由两个连续的低点在同一水平形成的看涨反转形态，随后向上突破。
  • 三重顶 — 在同一水平有三个高点的看跌反转形态。比双顶更强。
  • 三重底 — 在同一水平有三个低点的看涨反转形态。比双底更强。
  • 上升扩张楔形 — 成熟上升趋势中的看跌反转形态。两条线都上升但发散,产生不断增长的波动性。下方线突破触发强劲修正。止损位于最近高点之上,目标 = 楔形高度向下投影。
  • 看跌扩张三角形(看涨反转) — 下跌趋势末期的看涨反转形态。卖压减弱,买家在不断上升的低点出现。向上突破 = 新的看涨周期。双重入场,止损位于最近低点之下。
  • 看跌扩张三角形(看跌反转) — 上升趋势之后的看跌反转。更高的高点逐渐减弱,买家失去控制。下方支撑突破确认趋势变化。
  • V形底（看涨反转） — 急速反转形态：持续下跌后价格形成尖锐的V形低点并强劲反弹。确认从看跌到看涨的趋势转变。
  • 上升楔形 — 看跌反转形态。两条线上升但收敛。下线突破触发强劲下跌。
  • 下降楔形 — 看涨反转形态。两条线下降但收敛。上线突破确认趋势变化。
  • 下降扩张楔形 — 看涨反转。线下降但扩散，波动上升。向上突破爆炸性。
  • 看涨菱形 — 罕见但可靠的看涨反转。下跌后形成菱形（扩张+收缩）。
  • 看跌菱形 — 罕见但可靠的看跌反转。上涨后形成菱形。
  • V形顶 — 急速看跌反转：上涨后形成尖锐倒V高点并急跌。
  • 碟形（Saucer） — 缓慢看涨反转。宽阔U形曲线。
  • 圆顶 — 圆顶或倒U形看跌反转。
  • 圆底 — 平滑U形看涨反转。
  • 对称扩张（看涨） — 看涨反转（喇叭口）。上下线对称扩散。
  • 对称扩张（看跌） — 看跌反转（喇叭口）。上下线对称扩散。
  • 直角上升扩张 — 看跌反转。下线水平，上线上升扩散。
  • 直角下降扩张 — 看涨反转。上线水平，下线下降扩散。
  • V形底（看涨延续） — 上升趋势内的延续形态：价格做出小V形回调并通过突破前期高点恢复上升。用于加仓。
  • 上升三角形 — 具有平坦阻力线和上升支撑线的看涨持续形态。
  • 下降三角形 — 具有平坦支撑线和下降阻力线的看跌持续形态。
  • 对称三角形 — 具有对称收敛线的中性形态。突破可能是看涨或看跌。
  • 对称三角形看涨 — 向上突破的对称三角形，继续之前的上升趋势。
  • 对称三角形看跌 — 向下突破的对称三角形，继续之前的下降趋势。
  • 看涨旗形 — 强劲上升趋势后的短期持续形态，显示在进一步上涨前的盘整。
  • 看跌旗形 — 强劲下降趋势后的短期持续形态，显示在进一步下跌前的盘整。
  • 三角旗 — 强势走势后出现的小型三角持续形态。
  • 看涨三角旗 — 上升趋势中的对称持续形态，类似小旗形。
  • 看跌三角旗 — 下降趋势中的对称持续形态，类似小旗形。
  • 上升通道 — 具有平行上升趋势线的看涨形态，用于支撑和阻力。
  • 下降通道 — 具有平行下降趋势线的看跌形态，用于支撑和阻力。
  • 水平通道 — 具有水平支撑和阻力的盘整形态，显示横向价格走势。
  • 水平通道看涨 — 向上突破的水平通道，看涨持续信号。
  • 水平通道看跌 — 向下突破的水平通道，看跌持续信号。
  • 杯柄形 — 看涨持续形态，看起来像带手柄的杯子，表示可能的上涨走势。
  • 看涨扩张三角形(延续) — 看涨延续形态。上升扩张楔形在上升趋势内充当积累区。向上突破确认延续。T1 = 最小高度,T2 = 完整投影高度。
  • 看跌扩张三角形(延续) — 看跌延续形态。明确下跌趋势中的波动暂停,然后恢复下跌。向下突破确认延续,目标等于形态高度。

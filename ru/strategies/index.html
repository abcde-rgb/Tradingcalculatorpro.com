Все опционные стратегии

66 стратегий

Начать 7 дней бесплатно →
  • Long Call · BUY — ПОКУПКА Call. Платите премию. Неограниченная прибыль, если базовый актив поднимется выше Strike + Премия…
  • Short Put (CSP) · SELL — ПРОДАЕТЕ Put, обеспеченный деньгами. Получаете премию. Если падает ниже страйка, акция назначается по…
  • Bull Call Spread — Покупка call нижнего + продажа call верхнего. Определенный дебет.
  • Bull Put Spread — Продажа put верхний + покупка put нижний. Бычий чистый кредит.
  • Call Ratio Backspread — Продажа 1 call ATM + покупка 2 calls OTM. Неограниченный потенциал вверх.
  • Collar — Акция + покупка put OTM + продажа call OTM. Защита со сниженной стоимостью.
  • Synthetic Long — Покупка call ATM + продажа put ATM. Имитирует длинную позицию по акциям.
  • Long Combo — Покупка call OTM + продажа put OTM. Бычья экспозиция с меньшим капиталом.
  • Long Put · BUY — ПОКУПАЕТЕ Put. Платите премию. Прибыль, если базовый актив упадет ниже Strike − Премия (break-even).
  • Short Call (Naked) · SELL — ПРОДАЕТЕ непокрытый Call. Получаете премию. НЕОГРАНИЧЕННЫЙ риск вверх. Требует высокую маржу.
  • Bear Put Spread — Покупка put верхнего + продажа put нижнего. Медвежий дебет.
  • Bear Call Spread — Продажа call нижний + покупка call верхний. Медвежий кредит.
  • Put Ratio Backspread — Продажа 1 put ATM + покупка 2 puts OTM. Большая прибыль при сильном падении.
  • Synthetic Short — Покупка put ATM + продажа call ATM. Имитирует короткую позицию по акциям.
  • Short Combo — Продажа call OTM + покупка put OTM. Медвежья экспозиция с меньшим капиталом.
  • Covered Call — Длинная акция + продажа call OTM. Доход от позиции.
  • Iron Condor — Продажа put spread + call spread OTM. Прибыль в диапазоне.
  • Iron Butterfly — Продажа straddle ATM + покупка крыльев OTM. Максимальный кредит на ATM.
  • Butterfly Call — Покупка 1 call низкого + продажа 2 ATM + покупка 1 высокого.
  • Butterfly Put — Покупка 1 put высокого + продажа 2 ATM + покупка 1 низкого. Версия put.
  • Jade Lizard — Short put spread + непокрытый short call. Риск вверх отсутствует, если кредит > ширина put.
  • Short Straddle — Продажа call + put на одном страйке ATM. Максимальная Theta, высокий риск.
  • Short Strangle — Продажа call OTM + put OTM. Прибыль в широком диапазоне.
  • Ratio Call Spread — Покупка 1 call ATM + продажа 2 calls OTM. Нейтрально-бычья с кредитом.
  • Ratio Put Spread — Покупка 1 put ATM + продажа 2 puts OTM. Нейтрально-медвежья с кредитом.
  • Broken Wing Butterfly — Асимметричный Butterfly. Покупка 1 низкого + продажа 2 ATM + покупка 1 более OTM.
  • Long Straddle — Покупка call + put с одним strike. Прибыль при сильном движении.
  • Long Strangle — Покупка call OTM + put OTM. Дешевле, чем straddle.
  • Reverse Iron Condor — Покупка strangle + продажа strangle более OTM. Прибыль при пробое диапазона.
  • Reverse Iron Butterfly — Покупка straddle ATM + продажа крыльев OTM. Прибыль при движении.
  • Long Guts — Покупка call ITM + put ITM. Похоже на straddle, но с внутренней стоимостью.
  • Strap — Покупка 2 calls + 1 put с одним strike. Волатильная с бычьим уклоном.
  • Strip — Покупка 1 call + 2 puts с одним strike. Волатильная с медвежьим уклоном.
  • Cash Secured Put — Продажа пута с полным резервированием страйка наличными. Выплата как у короткого пута, но капитал заморожен…
  • Protective Put — Акции плюс купленный ниже пут: страховка с франшизой.
  • Covered Put — Шорт по акциям плюс проданный пут. Приносит премию, пока цена не растёт.
  • Covered Strangle — Акции плюс проданные вне денег колл и пут. Двойная премия и обязательства с обеих сторон.
  • Ratio Call Write — Акции с двумя проданными коллами: один покрытый, один непокрытый.
  • Ratio Put Write — Шорт по акциям с двумя проданными путами: один покрытый, один непокрытый.
  • Stock Repair — На убыточной позиции: один купленный колл и два проданных выше, чтобы снизить точку безубыточности без новых…
  • Call Calendar Spread — Продать ближний колл и купить такой же дальний. Живёт за счёт того, что время быстрее уходит у короткой ноги.
  • Put Calendar Spread — Продать ближний пут и купить такой же пут с более дальней экспирацией.
  • Call Diagonal Spread — Календарь с разными страйками: более высокая короткая нога добавляет бычий уклон.
  • Put Diagonal Spread — Пут-календарь с разными страйками: более низкая короткая нога добавляет медвежий уклон.
  • Double Calendar — Два календаря: пут ниже и колл выше. Прибыль, если цена окажется между ними.
  • Double Diagonal — Двойной календарь с более дальними длинными ногами: расширяет зону прибыли ценой большего дебета.
  • Jelly Roll — Разница двух синтетиков на одном страйке в двух экспирациях. Цена — чистая ставка и дивиденд.
  • Poor Man's Covered Call — Глубоко в деньгах дальний колл заменяет акции, против него продаётся ближний колл. Covered call без покупки…
  • ZEBRA — Два купленных колла в деньгах против одного проданного: дельта около 100 без чистой временной стоимости.
  • Risk Reversal — Финансирует купленный колл продажей пута. Бычий синтетик почти без затрат.
  • Seagull Spread — Risk reversal с ограничением сверху проданным коллом: дешевле в обмен на отказ от последнего участка.
  • Big Lizard — Проданный стрэддл с купленным выше коллом: убирает риск наверху, оставляя только нижний.
  • Reverse Jade Lizard — Проданный колл плюс проданный пут-спред: без риска снизу, с риском сверху.
  • Long Call Condor — Четыре колла, задающие плато прибыли между двумя внутренними страйками.
  • Long Put Condor — Тот же кондор, полностью построенный на путах.
  • Long Put Butterfly — Пут-бабочка: максимум на центральном страйке, риск ограничен дебетом.
  • Put Broken Wing Butterfly — Пут-бабочка с одним более широким крылом. Обычно открывается с кредитом и переносит весь риск на одну сторону.
  • Christmas Tree Butterfly (Call) — Асимметричная колл-бабочка 1-3-2: дешевле классической, зона прибыли смещена.
  • Christmas Tree Butterfly (Put) — Пут-версия бабочки 1-3-2, смещённая вниз.
  • Bull Call Ladder — Bull call spread с третьим проданным выше коллом. Дополнительный кредит открывает неограниченный риск сверху.
  • Bear Call Ladder — Колл продан внизу, два куплены выше: теряет в диапазоне, выигрывает на сильном росте.
  • Bull Put Ladder — Пут продан вверху, два куплены ниже: теряет в диапазоне, выигрывает на резком падении.
  • Bear Put Ladder — Bear put spread с третьим проданным ниже путом. Дополнительный кредит открывает риск снизу.
  • Box Spread — Bull call spread плюс bear put spread на тех же страйках. Стоит дисконтированной разницы страйков: это…
  • Conversion — Акции плюс купленный пут и проданный колл на одном страйке: позиция без направленного риска, стоимость…
  • Reversal — Обратная конверсия: шорт по акциям, купленный колл и проданный пут.
